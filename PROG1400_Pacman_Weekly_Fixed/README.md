# PROG1400 Pac-Man (Tile-by-Tile) — Weekly Snapshots (Fixed v2)

This package contains runnable weekly snapshots aligned to the PROG1400 teaching roadmap.

## Requirements
- Python 3.10+ recommended
- pygame 2.x

Install pygame:

    pip install pygame

## Run a week

    cd week06
    python app.py

Controls:
- Arrow keys: move
- R: restart current level
- Esc: quit
- P: pause (Week 14+)

**Important:** These snapshots resolve level paths relative to the folder containing `model.py`,
so they run correctly from VS Code or any working directory.
