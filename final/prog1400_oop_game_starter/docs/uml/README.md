# UML Diagram Pack

This folder contains Mermaid diagrams for the PROG1400 OOP game starter project.

## Included Diagrams

1. `01_class_diagram.mmd` - class relationships for the starter repo
2. `02_sequence_player_turn.mmd` - player input and movement sequence
3. `03_sequence_enemy_chase.mmd` - enemy chase and collision flow
4. `04_activity_game_loop.mmd` - overall activity / gameplay flow
5. `05_state_player.mmd` - player state transitions
6. `06_state_level.mmd` - level lifecycle states
7. `07_component_view.mmd` - module and file dependencies

## How to Use

- Open the `.mmd` files in VS Code with a Mermaid preview extension.
- Use them as teaching visuals in workshops.
- Ask students to modify the diagrams to match their own game design.

## Teaching Suggestions

- Start with the class diagram in Workshop 1 or 2.
- Introduce the sequence diagrams when students begin movement and enemy logic.
- Use the state diagrams when discussing win/lose conditions and power-up rules.
- Ask students to create their own updated diagrams for assessment evidence.
