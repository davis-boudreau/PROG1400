# PROG1400 – Object Responsibilities Worksheet

**Workshop 2 Rubric (100 points)**  
**Rubric Type:** Analytic  
**Scoring Method:** Points  
**Submission:** Word document

***

## 1. Object Identification & Context Understanding

**(Section 1 & 2)** — **25 points**

| Level                         | Description                                                                                                                                                                                                                                               |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Exceeds Expectations (25)** | Clearly identifies a comprehensive and appropriate set of game objects. Descriptions demonstrate a strong understanding of object-oriented thinking and game context. Object purposes are logical, well-justified, and clearly distinct from one another. |
| **Meets Expectations (21)**   | Identifies appropriate objects for the game with clear descriptions. Most object purposes are logical and relevant, with only minor gaps or overlap.                                                                                                      |
| **Developing (18)**           | Identifies some relevant objects, but the list may be incomplete, overly generic, or include objects that are not well justified. Contextual understanding is partial.                                                                                    |
| **Needs Revision (13)**       | Objects are poorly chosen, unclear, or demonstrate misunderstanding of object identification. Descriptions are vague or incorrect.                                                                                                                        |
| **Not Attempted (0)**         | Section missing or not meaningfully completed.                                                                                                                                                                                                            |

***

## 2. Object Responsibilities: Data Ownership

**(Section 3 – “Data it owns”)** — **25 points**

| Level                         | Description                                                                                                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Exceeds Expectations (25)** | Data ownership is clearly and correctly assigned to each object. Demonstrates strong understanding of encapsulation and responsibility boundaries. No inappropriate data assignments. |
| **Meets Expectations (21)**   | Data ownership is mostly correct and appropriate. Minor issues with placement or specificity, but overall understanding is clear.                                                     |
| **Developing (18)**           | Some correct data assignments, but several are unclear, incomplete, or assigned to inappropriate objects. Understanding of encapsulation is emerging.                                 |
| **Needs Revision (13)**       | Data ownership is frequently incorrect or missing. Shows limited understanding of object responsibility or encapsulation.                                                             |
| **Not Attempted (0)**         | Section missing or not meaningfully completed.                                                                                                                                        |

***

## 3. Object Responsibilities: Actions & Behaviors

**(Section 3 – “Actions it performs”)** — **20 points**

| Level                         | Description                                                                                                                                        |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Exceeds Expectations (20)** | Actions are well-defined, realistic, and clearly aligned with each object’s role. Behaviors reflect strong abstraction and separation of concerns. |
| **Meets Expectations (17)**   | Actions are appropriate and logical for most objects. Minor issues with clarity or depth, but overall responsibilities are sound.                  |
| **Developing (14)**           | Actions are listed but may be vague, repetitive, or not always appropriate for the object. Abstraction is inconsistent.                            |
| **Needs Revision (10)**       | Actions are unclear, incorrect, or frequently assigned to inappropriate objects. Limited understanding of object behavior.                         |
| **Not Attempted (0)**         | Section missing or not meaningfully completed.                                                                                                     |

***

## 4. Responsibility Boundaries (“What it should NOT do”)

**(Section 3)** — **15 points**

| Level                         | Description                                                                                                                                                            |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Exceeds Expectations (15)** | Clearly and correctly defines responsibility boundaries for each object. Demonstrates strong understanding of separation of concerns and prepares well for UML design. |
| **Meets Expectations (13)**   | Responsibility boundaries are mostly correct and reasonable. Some boundaries could be clearer or more precise.                                                         |
| **Developing (11)**           | Boundaries are partially defined but may be vague, incomplete, or inconsistent across objects.                                                                         |
| **Needs Revision (8)**        | Boundaries are mostly missing, incorrect, or demonstrate misunderstanding of object responsibilities.                                                                  |
| **Not Attempted (0)**         | Section missing or not meaningfully completed.                                                                                                                         |
