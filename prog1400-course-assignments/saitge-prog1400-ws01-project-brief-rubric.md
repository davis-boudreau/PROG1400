# **PROG1400 – Project Brief (UML v0) Rubric**

**Total: 100%**  
**Assessment Type:** Formative (Feedback Only – No Grade)

***

## **1. Game Concept Overview (Section 1) – 15%**

*Game type, objective, win/lose conditions clearly described in 3–5 sentences.*

| Level                   | Description                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| **Exceeds (15%)**       | Game concept is clear, engaging, and precise; all required elements are explicitly stated. |
| **Meets (12%)**         | Game type, objective, and win/lose conditions are clearly described.                       |
| **Developing (8%)**     | Concept is understandable but missing or unclear in one required area.                     |
| **Needs Revision (4%)** | Concept is vague, incomplete, or difficult to understand.                                  |

***

## **2. Core Gameplay Mechanics (Section 2) – 15%**

*Player movement, challenges/obstacles, and scoring or progression.*

| Level                   | Description                                                                                   |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| **Exceeds (15%)**       | Gameplay mechanics are clearly explained; progression or difficulty changes are well defined. |
| **Meets (12%)**         | Movement, challenges, and scoring/progression are adequately described.                       |
| **Developing (8%)**     | One or more gameplay elements are unclear or underdeveloped.                                  |
| **Needs Revision (4%)** | Gameplay mechanics are poorly described or mostly missing.                                    |

***

## **3. Pac‑Man Inspiration & Alignment (Section 3) – 15%**

*Clear similarity to Pac‑Man without copying it directly.*

| Level                   | Description                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------- |
| **Exceeds (15%)**       | Strong connection to Pac‑Man concepts with clear originality and thematic distinction. |
| **Meets (12%)**         | Similarities to Pac‑Man are clearly explained and appropriate.                         |
| **Developing (8%)**     | Similarity is mentioned but weakly justified or unclear.                               |
| **Needs Revision (4%)** | Game does not clearly align with the Pac‑Man case study.                               |

***

## **4. Object Identification & Suitability (Section 4) – 20%**

*At least 5 conceptual objects, each with a clear role.*

| Level                   | Description                                                              |
| ----------------------- | ------------------------------------------------------------------------ |
| **Exceeds (20%)**       | 7+ well‑chosen objects; roles are clear, distinct, and suitable for OOP. |
| **Meets (16%)**         | 5+ appropriate objects with understandable descriptions.                 |
| **Developing (10%)**    | Fewer than 5 objects or vague/overlapping descriptions.                  |
| **Needs Revision (5%)** | Objects are missing or not appropriate for object‑oriented design.       |

***
