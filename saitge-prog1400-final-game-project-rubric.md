# 📎 Required Deliverables

Students must submit:

1. Final working game (Python + Pygame)
2. Updated UML diagram
3. GitHub repository link
4. Reflection (500–750 words):

   * Key design decisions
   * Biggest debugging challenge
   * OOP principle they improved most
   * What they would improve with more time

---

# 🎯 What “A-Level” Work Looks Like

An A-level submission:

* Demonstrates true OOP thinking (not just classes used mechanically)
* Separates engine, entities, and game state cleanly
* Handles edge cases (collision boundaries, restart logic)
* Shows deliberate refactoring
* Is portfolio-ready
